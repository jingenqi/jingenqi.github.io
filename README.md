# Enqi Jing Portfolio

A quiet, editorial personal portfolio for Enqi Jing, focused on research, distributed systems, machine learning, and risk intelligence.

## Stack

- React 18
- Vite
- React Router
- Lucide icons
- Native CSS design tokens

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The build creates optimized assets plus static HTML route shells for every public page and case study. This keeps direct GitHub Pages routes refreshable and gives each route independent canonical, Open Graph, and description metadata.

## Content

Public facts live in `src/content/`. The downloadable resume is `public/Enqi_Jing_Resume_File.pdf`. Do not duplicate or invent biography, project, metric, or contact information inside page components.

The complete redesign specification is in `docs/apple-portfolio-redesign-spec.md`. Its implementation status and validation evidence are recorded in `docs/apple-portfolio-implementation-audit.md`.
